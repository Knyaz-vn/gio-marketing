=== SVT Meta Generator ===
Requires at least: 6.0
Requires PHP: 8.0
Stable tag: 1.0.0
License: GPLv2 or later

Генерація meta description через Claude API (Anthropic) для товарів WooCommerce, категорій товарів, сторінок і записів.
Російська та українська версії сайту (Polylang/WPML): кожен опис пишеться мовою свого запису.

== Встановлення ==

1. Адмінка → Плагіни → Додати новий → Завантажити плагін → svt-meta-generator.zip → Встановити → Активувати.
2. (Рекомендовано) додайте ключ у wp-config.php над рядком "That's all, stop editing!":
   define( 'SVTMG_API_KEY', 'sk-ant-...' );
   Або вставте ключ у Налаштування → SVT Meta Generator (константа має пріоритет).
3. Налаштування → SVT Meta Generator: натисніть "Перевірити з'єднання", перевірте типи записів і таксономії, збережіть.
4. Поле "Шаблонні описи" вже містить фрагмент поточного шаблону Yoast: На рынке с 1997 года
   Описи з цим фрагментом вважаються порожніми й будуть замінені, а написані вручну лишаться.
5. "Покриття за мовами" → "Порахувати": таблиця RU / UK показує, скільки об'єктів уже мають опис, а скільки порожні,
   шаблонні або з описом іншою мовою.
6. Масова генерація: спершу "Не більше: 20" і перевірте результат у колонці "Meta description", потім 0 (без обмеження).

== Дві мови (RU + UK) ==

* Мова кожного товару, сторінки й категорії береться з Polylang (або WPML). Російський об'єкт отримує опис російською
  за російським промптом, український — українською за українським. Переклади генеруються окремо, кожен своєю мовою.
* Опис не тією мовою (наприклад, Polylang скопіював російський опис в український переклад) вважається порожнім:
  його видно з позначкою "інша мова" і він потрапляє в масову генерацію та автогенерацію без увімкненого перезапису.
  Мова визначається за літерами: і, ї, є, ґ (укр.) та ы, э, ъ, ё (рос.).
* Під час створення перекладу Polylang більше не копіює meta description (_yoast_wpseo_metadesc, rank_math_description,
  _svtmg_meta_description), тож новий переклад одразу отримує власний опис своєю мовою.
* У масовій генерації можна вибрати мову: усі, лише російська або лише українська.

== Де зберігаються описи ==

* Yoast SEO: товари/сторінки → _yoast_wpseo_metadesc; категорії → опис терміна в Yoast (wpseo_taxonomy_meta).
* Rank Math: rank_math_description (мета запису / терміна).
* Без SEO-плагіна: _svtmg_meta_description, плагін сам виводить <meta name="description"> і og:description
  (дублікати автоматично прибираються).

== Що бачить модель ==

* Товар: назва, бренд (product_brand або атрибут pa_trademark), категорія, видимі характеристики (атрибути),
  короткий і повний опис. Ціна, наявність і знижки не передаються: вони змінюються.
* Категорія: назва, розділ каталогу, підкатегорії, 12 прикладів товарів, бренди серед них, текст опису категорії.
* Сторінка/запис: заголовок, H1, текст (зі сторінок Elementor — з _elementor_data).

== Використання ==

* Автоматично: після публікації товару чи сторінки, а також після створення категорії з порожнім описом об'єкт стає в чергу.
  Масовий імпорт товарів теж іде через чергу з паузами, тож запити не підуть до API всі одночасно.
* Вручну: блок "Meta description (SVT)" у редакторі товару/сторінки та у формі редагування категорії.
* Списки товарів, сторінок і категорій: колонка "Meta description" і групова дія "Згенерувати опис".
* Лог помилок (останні 50) — внизу сторінки налаштувань.

== Примітки ==

* WP-Cron запускається відвідуванням сайту. При DISABLE_WP_CRON масова генерація йде, поки відкрита сторінка
  налаштувань; для фонової роботи потрібен системний cron.
* Видалення плагіна прибирає налаштування і лог. Згенеровані описи лишаються.
* Фільтри: svtmg_source_text, svtmg_source_max_chars, svtmg_product_facts, svtmg_term_facts, svtmg_brand_attributes,
  svtmg_elementor_widget_text, svtmg_generated_description, svtmg_bulk_batch_size, svtmg_request_pause,
  svtmg_max_retries, svtmg_max_tokens, svtmg_output_enabled, svtmg_pll_exclude_meta_keys. Дія: svtmg_description_saved.
