# Інтерактивний гід з підготовки до аналізів — BP Medical

Модуль для сайту bpmedical.com.ua. Пацієнт обирає процедури й отримує персональний чек-лист:
скільки годин не їсти (з розрахунком від часу запису), що скасувати заздалегідь, що взяти з собою,
порядок проходження в один день і попередження про несумісні поєднання (наприклад, ПСА після ТРУЗД).

## Що всередині
- 26 процедур у 8 категоріях. Включено лише послуги, які є на сайті клініки: лабораторія, УЗД, ЕКГ,
  ФГДС/колоноскопія, кольпоскопія, пункції/біопсії, трихоскопія/дерматоскопія, КТ/МРТ/ПЕТ-КТ (Онкоінститут).
- Пошук, фільтр за категоріями, копіювання чек-листа (для Viber/Telegram), «Поділитися», друк / PDF.
- Посилання з вибором: `...#bpg=bio,uzd-abd` одразу відкриває гід з обраними процедурами
  (зручно для SMS-нагадувань і відповідей адміністратора).
- Події для GA4/GTM: `prep_guide_select`, `prep_guide_call`, `prep_guide_copy`, `prep_guide_share`, `prep_guide_print`.

## Як вставити у WordPress
Скопіюйте все між коментарями `ПОЧАТОК МОДУЛЯ` і `КІНЕЦЬ МОДУЛЯ` з `index.html` у блок «Власний HTML».
Стилі ізольовані під `#bpg`, залежностей немає. Кольори змінюються у змінних `--bpg-*` на початку стилів.

## Перед публікацією
- Звірте перелік процедур з актуальним прайсом (сайт клініки був недоступний для автоматичного
  перегляду, перелік зібрано з проіндексованих сторінок). Процедури редагуються в масиві `TESTS`.
- Узгодьте тексти підготовки з лікарями клініки (особливо колоноскопію, ПЕТ-КТ, біопсії).
